 Bulk Import Payments from CSV

How to use:

  1. Download the template below, fill it in using Excel or Google Sheets
  2. Save as CSV and upload it here, OR paste the CSV text directly
  3. Each row = one payment receipt for one student
  4. Date format: YYYY-MM-DD (e.g. 2026-10-15)
  5. Amount: numbers only, no currency symbol (e.g. 35000)
  6. Category options: school_fees, bus_fee, uniform_fee, textbook_fee, exam_fee, sport_fee, stationery_fee, development_levy, misc_1
  7. Method: Cash, Bank Transfer, POS, or Cheque
